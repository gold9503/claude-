# ⛳ 경북북부 골프날씨

경북 북부 골프장별 **현재 위치에서의 거리 · 실시간 날씨 · 그린피**를 한 화면에 보여주는 안드로이드용 웹앱(PWA)입니다.
설치형 앱처럼 홈 화면에 아이콘으로 추가해서 쓸 수 있고, 별도 서버나 API 키가 필요 없습니다.

## 기능
- **골프장 목록**: 안동레이크GC, 안동리버힐CC, 한맥CC&노블리아(예천), 문경GC, 블루원 상주CC, 엠스클럽 의성, 울진마린CC
- **거리**: 휴대폰 GPS 기준 직선거리와 대략적인 이동시간 (위치 권한이 없으면 안동시청 기준)
- **날씨**: 현재 기온·체감·바람·습도·강수확률, 12시간 시간별 예보, 일몰 시각 ([Open-Meteo](https://open-meteo.com/) 무료 API)
- **라운드 적합도 점수**: 비·바람·기온·뇌우를 반영한 0~100점 (좋음 / 보통 / 비추천)
- **그린피**: 주중/주말 표시. 카드의 그린피를 눌러 **직접 수정** 가능 (휴대폰에 저장됨)
- 정렬(거리·적합도·그린피·이름), 지역 필터, 카카오맵 길찾기, 예약 전화 버튼
- 오프라인에서도 마지막 날씨로 열림

> ⚠️ 그린피는 참고용 기본값입니다. 시즌·시간대·이벤트에 따라 수시로 바뀌니 예약 전 골프장에 확인하세요.
> 골프장 좌표는 대략값이며, 길찾기는 카카오맵에서 골프장 이름으로 검색해 정확한 위치로 안내합니다.

## 📱 APK 바로 설치 (추천)
1. 휴대폰에서 **https://github.com/gold9503/claude-/releases/latest** 접속
2. **golf-weather.apk** 를 눌러 다운로드 → 다운로드 완료 알림을 눌러 설치
   - "출처를 알 수 없는 앱" 경고가 나오면 **설정 → 이 출처 허용** 을 켜고 다시 설치
   - Play 프로텍트 경고가 나오면 **무시하고 설치** (개인용으로 직접 만든 앱이라 나오는 경고입니다)
3. 앱 실행 → 위치 권한 **허용**

코드를 푸시할 때마다 GitHub Actions(`.github/workflows/android.yml`)가 새 APK를 만들어 Releases에 올립니다.
같은 서명키로 만들기 때문에 새 버전을 받으면 기존 앱 위에 덮어 설치(업데이트)됩니다.

## 웹앱(PWA)으로 설치하기
1. 이 저장소의 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 설정합니다.
2. 푸시하면 `.github/workflows/pages.yml` 이 자동으로 배포합니다. 주소: `https://<GitHub아이디>.github.io/<저장소이름>/`
3. 안드로이드 **크롬**으로 그 주소를 열고 → 위치 권한 **허용** → 상단의 **「📲 홈 화면에 앱 설치」** 버튼
   (또는 크롬 메뉴 ⋮ → **앱 설치 / 홈 화면에 추가**) 를 누르면 앱 아이콘이 생깁니다.

> 위치(GPS) 기능은 보안상 **https** 주소에서만 동작합니다. GitHub Pages는 https라 그대로 쓰면 됩니다.

## 골프장 추가·수정
`courses.js` 파일에 항목을 추가하면 됩니다.

```js
{
  id: "new-cc", name: "새 골프장CC", region: "봉화군",
  address: "경북 봉화군 ...", holes: 18, type: "대중제",
  lat: 36.89, lng: 128.73, phone: "054-000-0000",
  feeWeekday: 120000, feeWeekend: 160000, note: "",
},
```

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html`, `style.css`, `app.js` | 화면과 동작 |
| `courses.js` | 골프장 데이터 (위치·그린피) |
| `manifest.webmanifest`, `sw.js`, `icons/` | 홈 화면 설치 · 오프라인 지원 |

## 로컬에서 실행
```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```
