# 🎼 기다림의 명언

기다리는 동안 켜두는 안드로이드 앱입니다. 실행할 때마다 **명언이 무작위로** 나오고, 배경에는 **클래식 피아노 음악**이 흐릅니다.

## 📱 설치
1. 휴대폰에서 **https://github.com/gold9503/claude-/releases/download/quotes-latest/wise-quotes.apk** 를 열어 다운로드
2. 다운로드 완료 알림을 눌러 설치
   - "출처를 알 수 없는 앱" 경고 → **설정 → 이 출처 허용** 후 다시 설치
   - Play 프로텍트 경고 → **무시하고 설치** (개인용으로 직접 만든 앱이라 나오는 경고입니다)

## 기능
- 명언 105개를 섞어서 한 번씩 다 보여주기 전까지는 같은 명언이 반복되지 않음
- 화면을 **누르면** 다음 명언, **길게 누르면** 명언 복사, 30초마다 자동으로 바뀜
- 배경음악 3곡을 이어서 반복 재생 (하단 곡 이름을 누르면 다음 곡) · **음악 끄기/켜기** 버튼 (설정 기억)
- 앱을 켜둔 동안 화면이 꺼지지 않음, 앱을 나가면 음악도 멈춤

## 음악
| 곡 | 작곡가 |
|---|---|
| 평균율 클라비어곡집 1권 프렐류드 C장조 BWV 846 | J.S. 바흐 |
| 캐논 D장조 (피아노 편곡) | 요한 파헬벨 |
| 엘리제를 위하여 WoO 59 | 베토벤 |

모두 퍼블릭 도메인 곡이며, 녹음 저작권 문제가 없도록 `tools/make_music.py` 로 악보를 직접 피아노 소리로 합성했습니다.
다시 만들려면: `python3 tools/make_music.py app/src/main/res/raw` (numpy, ffmpeg 필요)

## 명언 추가·수정
`app/src/main/assets/quotes.txt` 에 `명언|말한 사람` 형식으로 한 줄씩 넣으면 됩니다.

푸시하면 GitHub Actions(`.github/workflows/quotes-android.yml`)가 APK를 새로 만들어 위 주소에 덮어씁니다.
